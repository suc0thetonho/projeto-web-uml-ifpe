Como montar a matriz curricular

A matriz curricular é a última etapa da criação de um PPC. Nela você cadastra todos os componentes curriculares do curso, um a um.

Pré-requisito: Para chegar nesta tela, é necessário ter concluído as etapas anteriores (Dados do Campus, Dados do Curso e Informações Complementares). Se ainda não fez isso, consulte o tutorial Como criar um Novo PPC.
1

Acesse a etapa de Componentes Curriculares

Após completar a etapa 3 e clicar em Próximo, o sistema abrirá automaticamente a tela Novo PPC — Informações dos Componentes Curriculares. Se você estava editando um PPC em andamento, os componentes já cadastrados serão exibidos na tabela.

2

Preencha os dados do componente curricular

O formulário no topo da tela possui os seguintes campos (os marcados com * são obrigatórios):

  • Código * — código de identificação da disciplina (ex.: INF001)
  • Nome do Componente Curricular * — nome da disciplina
  • Créditos de aulas práticas *
  • Créditos de aulas teóricas *
  • Créditos de Extensão *
  • Total de Horas Práticas (H/R) *
  • Total de Horas Teóricas (H/R) *
  • Total de Horas de Extensão (H/R) *
  • Tipo * — ex.: Obrigatória, Optativa
  • Período * — período/semestre em que a disciplina é ofertada
  • Pré-requisitos (opcional)
  • Correquisitos (opcional)
3

Clique em "+ Adicionar componente"

Após preencher os campos, clique no botão + Adicionar componente. O sistema verificará que todos os campos obrigatórios foram preenchidos e adicionará o componente à tabela de componentes curriculares abaixo do formulário.

Os campos do formulário serão limpos automaticamente, pronto para o próximo cadastro.

4

Repita para cada disciplina da grade

Repita os passos 2 e 3 para cada componente curricular do curso. Você pode adicionar quantos componentes forem necessários. A tabela exibirá todos os componentes já cadastrados, organizados por período.

Atenção: não há botão "Salvar rascunho" nesta etapa. Os componentes são salvos automaticamente no banco de dados ao clicar em + Adicionar componente.

5

Revise a tabela de componentes

Antes de finalizar, confira a tabela de componentes curriculares. Verifique se todos os períodos estão cobertos, se os códigos estão corretos e se as cargas horárias estão de acordo com o projeto pedagógico.

6

Clique em "Gerar Documento" para concluir

Quando toda a grade estiver cadastrada, clique em Gerar Documento. O sistema irá:

  • Marcar o PPC com status concluído
  • Redirecionar para a tela de PPCs cadastrados

A partir daí, você pode clicar no nome do PPC para ver todos os detalhes ou clicar em ⬇ PDF para baixar o documento gerado.

Tabela de componentes: os campos Pré-requisitos e Correquisitos são opcionais. Se uma disciplina não tiver pré ou correquisitos, deixe esses campos em branco.
